# MAGPIE RUNNING

러닝크루 대회 사진 갤러리입니다. 이 레포에 사진을 올리면 1~2분 뒤 사이트가 자동으로 바뀝니다.

사이트: https://opensmartyouth-art.github.io/magpierunning/

## 폴더 구조

```
events/
  2026/                         ← 연도
    seoul-half-marathon/        ← 대회 (폴더 이름이 주소가 됩니다)
      event.md                  ← 이름·날짜·소개
      001.jpg, 002.jpg …        ← 그 대회의 사진들
  2025/
    …
```

사이트 메뉴의 연도는 `events/` 아래 연도 폴더에서 자동으로 만들어집니다. 새 연도 폴더를 만들면 메뉴에 생깁니다.

## 하는 일 (GitHub 웹에서)

| 하려는 일 | 방법 |
| --- | --- |
| 사진 올리기 | 대회 폴더로 들어가 Add file → Upload files 로 끌어다 놓고 Commit changes |
| 제목·날짜·소개 고치기 | 대회 폴더의 `event.md` 를 열고 연필 아이콘으로 고친 뒤 Commit changes |
| 새 대회 만들기 | 연도 폴더 안에서 Add file → Create new file, 이름에 `새대회이름/event.md` 라고 쓰면 폴더가 만들어집니다. 내용을 아래 형식으로 쓰고 Commit한 뒤, 그 폴더에 사진을 올립니다 |
| 사진 지우기 | 사진 파일을 열고 휴지통 아이콘 |

폴더 이름은 영문 소문자와 하이픈(`seoul-half-marathon`)을 권장합니다. 한글이나 공백이 있으면 주소가 길어집니다.

## event.md 형식

맨 위를 `---`로 감쌉니다.

```
---
title: Seoul Half Marathon 2026
date: 2026-10-04
summary: 소개 문장 (선택, 영어로 쓰면 사이트와 맞습니다)
link: View the Results | https://… (선택, 소개 아래 밑줄 링크 한 줄)
cover: 003.jpg (선택, 목록에 보일 썸네일 사진. 없으면 첫 사진. 아래 '썸네일' 참고)
---
```

- `date` 는 `YYYY-MM-DD` 이고, 연도가 폴더 연도와 같아야 합니다(`2026/` 폴더면 2026-…).
- 목록은 날짜가 최신인 대회가 앞에 옵니다.
- 사진은 파일 이름 순서대로 나옵니다(`001`, `002` … 처럼 번호를 붙이면 순서를 정하기 쉽습니다).

## 썸네일 (대회 카드 이미지)

대회 목록과 연도 페이지에서 각 대회를 대표하는 이미지입니다.

### 설정 방법

대회 폴더의 `event.md`에 `cover` 한 줄을 추가합니다. 값은 그 대회 폴더 안에 있는 사진의 파일 이름입니다.

```
---
title: Busan Coastal 10K
date: 2026-08-23
cover: 003.jpg
---
```

`cover`를 쓰지 않으면 폴더 안에서 파일 이름순으로 첫 번째 사진이 썸네일이 됩니다(`001.jpg`가 있으면 그 사진). 이름에 오타가 있거나 폴더에 없는 파일을 쓰면 빌드가 실패하고, Actions 탭에서 이유를 읽을 수 있습니다.

썸네일로 고른 사진도 대회 상세 페이지의 사진 목록에 그대로 나옵니다. 썸네일 전용 파일(목록에서만 쓰고 상세에서는 빼는 방식)은 아직 지원하지 않습니다.

### 썸네일 규격

| 항목 | 값 |
| --- | --- |
| 카드 비율 | 세로 2:3 |
| 사이트가 만드는 크기 | 600×900px, 고해상도 화면용 1200×1800px |
| 권장 원본 | 세로 2:3 비율, 1200×1800px 이상 |
| 형식 | jpg, png, webp (아이폰 HEIC는 건너뜁니다) |
| 다른 비율일 때 | 사진의 정중앙을 기준으로 2:3으로 잘라서 사용 |

정중앙을 기준으로 자르기 때문에, 원본 비율에 따라 아래만큼 잘립니다. 인물이 한쪽에 치우친 사진은 미리 가운데로 크롭해서 올리는 것을 권장합니다. 자르는 기준점을 지정하는 기능은 아직 없습니다.

| 원본 비율 | 잘리는 정도 |
| --- | --- |
| 2:3 세로 | 잘리지 않음 |
| 3:4 세로 | 좌우가 각각 약 5.5% |
| 3:2 가로 | 좌우가 많이 잘려 중앙 약 44%만 남음 |

## 사진 규격 (대회 상세)

| 항목 | 값 |
| --- | --- |
| 형식 | jpg, png, webp |
| 비율 | 제한 없음. 가로·세로가 섞여도 원본 비율 그대로 나옵니다 |
| 권장 크기 | 긴 변 기준 1600px 이상 (사이트는 가로 1600px와 800px 두 가지로 줄여서 보여 줍니다) |
| 용량 | 웹에서 올릴 때 파일당 25MB 이하, 한 번에 100개까지 |
| 순서 | 파일 이름 순서(숫자는 크기순: `2.jpg`가 `10.jpg`보다 앞) |

원본이 1600px보다 작으면 늘리지 않고 원본 크기로 보여 줍니다. 사진 순서를 정하려면 `001.jpg`, `002.jpg`처럼 번호를 붙여 올립니다.

## 로고와 파비콘 바꾸기

레포 맨 위의 파일을 같은 이름으로 교체하고 Commit하면 됩니다.

| 파일 | 쓰임 |
| --- | --- |
| `Logo.svg` | 헤더의 처음 로고 |
| `Logo02.svg` | 스크롤을 내리면 바뀌는 로고 (0.5초 동안 서서히 바뀜) |
| `Favicon.png` | 브라우저 탭 아이콘 (정사각형 PNG 권장, 자동으로 32·180·192px 크기가 만들어집니다) |

두 로고는 같은 높이(28px)에 맞춰 가운데에 놓이므로 가로 폭은 달라도 됩니다. 높이를 바꾸려면 `site/gallery.css`의 `.site-name img { height: 28px; }`를 고칩니다.

## 알아 두실 점

- 사진은 jpg, png, webp 만 됩니다. 아이폰 사진(HEIC)은 건너뜁니다. 아이폰이면 설정에서 형식을 "호환성 우선(JPEG)"으로 바꾸거나 JPEG로 내보내 올려 주세요.
- 웹에서 올릴 때는 파일당 25MB, 한 번에 100개까지입니다. 더 많으면 나눠서 올립니다.
- 이 레포는 공개라서 올린 원본 사진도 레포에서 누구나 볼 수 있습니다. 사이트에는 줄인 사진만 올라갑니다.
- 올린 뒤 반영 상태는 위쪽 Actions 탭에서 볼 수 있습니다. 초록 체크면 반영 완료, 빨간 X면 실패입니다. 실패하면 열어서 이유(예: date 형식, event.md 없음)를 읽을 수 있습니다.

## 로컬에서 확인

```
npm install
npm run build        # dist/ 에 사이트 생성
cd dist && python3 -m http.server 4173
```

`site/` 는 빌드 스크립트와 CSS(ALD 디자인 시스템 `ssxekun-designsystem`에서 가져온 값)입니다. 폰트는 ALD 서버에서 불러옵니다.
